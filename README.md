# RWD Studio — project setup

React 19 and TypeScript with TanStack Start, file-based routing, Rsbuild, Tailwind CSS, and Biome.

## Development

```sh
pnpm install
pnpm dev
```

## Production build

```sh
pnpm build
```

Routes live in `src/routes`, global styles in `src/styles.css`, and build configuration in `rsbuild.config.ts`.
